# Contributing

Read the README, `RUNBOOK.md`, and relevant integration or data-handling docs before changing payment, messaging, or credential flows. Open an issue with a concise description and a reproducible example before proposing a broad change.

Use the checked-in npm lockfile. Do not commit `.env`, OAuth tokens, payment credentials, customer exports, production logs, or real contact data. Use provider sandboxes and fictional records in examples.

Available checks include `npm run typecheck` where configured, `npm run lint`, `npm test`, and `npm run build`. Note which checks you ran.
