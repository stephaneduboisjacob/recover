# Security Policy

RECOVER can process business, payment, customer, and OAuth data. Treat database dumps, logs, webhook payloads, provider credentials, and exports as sensitive.

Do not report suspected vulnerabilities in a public issue. Contact the maintainer privately at [jacobstephane@outlook.com](mailto:jacobstephane@outlook.com) with a concise description and safe reproduction steps. Do not attach real credentials, customer data, or production exports.

Provider integrations and compliance controls require deployment-specific review. This prototype is not a substitute for legal, accounting, or security advice.

Contact: Stephane Jacob <jacobstephane@outlook.com>
